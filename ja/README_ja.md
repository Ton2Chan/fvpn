# FVPN — Ultra-lightweight & Secure Linux CLI for FastestVPN

`fvpn` は、Linux 環境で FastestVPN を安全かつ快適に運用するために開発された、超軽量で堅牢な CLI（コマンドライン）VPN クライアントです。

コードの無駄を徹底的に削ぎ落とした**コンパクトでレスポンスの早い設計**でありながら、一瞬の隙も許さない**完全な DNS 漏洩保護**と、ネットワーク障害に強い**自己修復機能**を備えています。

---

## 💡 開発思想とアーキテクチャの核心

一般的な接続ツールの枠を超え、Linux のネットワークスタックにおける「安全性のスキマ」を徹底的に埋めることを目指して設計されています。

### 1. 接続開始から一瞬の隙も作らない「完全 DNS 保護」

一般的な VPN クライアントの多くは、VPN サーバーとの接続が確立された後に DNS 設定を切り替えるため、接続処理の初期段階（サーバーアドレスの問い合わせ等）で一瞬だけ生の DNS トラフィックが漏洩するリスクが存在します。

`fvpn` では、一部の高度な VPN アプリで採用されている「接続シーケンスの最初の最初から DNS トラフィックを厳格にロックアウトする」設計を採用しました。サーバーのサイレント IP 自動更新への追従性をあえてトレードオフにし、**接続開始から切断に至るまで、暗号化されていない DNS 問い合わせを一切許さない安全性**を最優先しています。

### 2. LOCKDOWN（キルスイッチ）の完全な状態維持

VPN 接続が切断された場合だけでなく、**LOCKDOWN（キルスイッチ）が有効な状態のまま安全にアプリを終了し、次回もその保護状態のまま起動する**ことができます。意図しない通信の漏洩を物理レベルで防ぎます。

### 3. 起動時の自動クリーンアップ（Self-Healing）

前回のセッションが異常終了（端末の突然のカットやクラッシュ）した場合でも、次回起動時に生 IP 状態を検知し、残存したルールやプロセスを自動的に初期化。常にクリーンで安定した状態からスタートします。

## ✨ 主な特徴

* **超軽量・高速動作**: 徹底的な省資源・コンパクトコード設計により、動作が非常に軽快です。
* **ワンタッチ簡易接続**: 注目サーバーや最適なノードへ即座に接続。
* **UDP / TCP 対応**: 用途やネットワーク環境に合わせて利用可能。
* **アップデートチェック**:
* サーバーリスト更新後、7 日間は自動チェックをスキップし、それ以降は 1 日ごとにチェックします。
* この動作期間は `setting.ini` 内のパラメータで柔軟に調整可能です。
UPDATE_CHECK_INTERVAL=7
UPDATE_RETRY_INTERVAL=1



---

## ⚠️ 重要な仕様上の注意（設定ファイルについて）

* `fvpn` は、**起動時に `data/` フォルダ内の設定ファイルをメモリへ読み込み、プログラムの終了時のみファイルへの書き出し（更新）を行います。**
* 手動で設定ファイル（`setting.ini` 等）を直接編集する場合は、**必ず `fvpn` を終了した状態で行ってください。**（実行中に編集すると、終了時に上書きされます）
